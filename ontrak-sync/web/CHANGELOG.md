# Changelog — OnTrak Sync

## 2.0.0 — 2026-10-24

The family re-baseline. The scan → findings → apply console, the four honest
answers per target, the approval gate and change freeze, SSO/break-glass and the
opt-in unattended container rolls are now **2.0.0**. Next: approval workflows and
maintenance calendars (2.1), canary/rollback and blast-radius caps (2.2),
inventory depth (2.3), per-team scope (2.4), fleet remediation (3.0) and
continuous compliance (4.0). No code changed in this release. See
[docs/roadmap.md](../docs/roadmap.md).

## 1.2.0 — 2026-10-19

A family release-train bump: no change to this product in this release, moved so the
Network package and container update line stays comparable with the rest of the
family. The backend (`ontrak-sync/backend`) carries no version field, so it is
released with this one and cannot drift from it.
