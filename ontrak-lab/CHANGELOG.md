# Changelog — OnTrak Lab

## 2.0.0 — 2026-10-24

The family re-baseline. The verified control plane, the Linux and Windows
templates, the golden-image pipeline, the Guacamole console, the ticket rubric, the
container stack and the one-command install are now **2.0.0**. Next: Microsoft
products beyond Office (2.1), a cloud-identity tenant sandbox (2.2), recording and
review (2.3), role-based portals (2.4), metrics (2.5), signed scenario packs (2.6),
a multi-host range (3.0) and federated ranges (4.0). No code changed in this
release. See [docs/roadmap.md](docs/roadmap.md).

## 0.2.0 — 2026-10-19

A family release-train bump: this deployment's own code is unchanged, and the
version moves so the lab is comparable with the six products it sits beside. The
Network still reaches it at `lab.ontrak.innotel.us`, which is the same name and the
same port it was published on before.

Deploying this release is the lab host's own job — this repository only carries its
tree (`ontrak-provision.py` deliberately does not deploy it).
