# Changelog — Uncensored Godmode (G0DM0D3)

## 2.0.0 — 2026-10-24

The family re-baseline. The metered front door to Genie — one credit per run, the
run id as idempotency key, refunds for a run that never produced a byte, SSO, the
per-user gateway key, the gateway's own model catalog, preview/ship, and the plan
gate on both the page and the route — is now **2.0.0**.

Next: run history (2.1), replay and diff (2.2), team credit pools (2.3), snapshot
and rollback (3.0) and delegated autonomous runs under signed consent (4.0). No
code changed in this release. See [docs/roadmap.md](docs/roadmap.md).

## 0.1.0

The product as it first shipped: a credit-metered page that takes a prompt, spends
a credit and streams Genie's answer.
